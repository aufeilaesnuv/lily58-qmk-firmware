# lily58-qmk-firmware

Features:
* Via support
* 6 usable layers
* The left OLED screen only displays the current layer number and the last pressed key, instead of the default longer keylog display

Usage:
* Place this in your qmk_firmware/keyboards/lily58/keymaps/aufeilaesnuv directory.
* Compile with `qmk compile -kb lily58 -km aufeilaesnuv` (or compile.sh)
* See how to set up qmk here: https://docs.qmk.fm/newbs_getting_started
